# UI Test Playground with Playwright & TypeScript
This project is a multi-page demo app that includes different testable user interactions such as  
form validation, dropdown logic, calendar rules and mini shopping cart. Tests are written 
using Playwright + TypeScript.

---

## ⚙️ Setup 
```bash
# 1. Install dependencies
$ npm install

# 2. Start local server
$ npx serve src -l 3000

# 3. Run Playwright tests
$ npx playwright test
```

---

## 🧱 Technologies
Project is created with: 
* Web page: HTML/CSS/TypeScript
* E2E testing framework: Playwright
